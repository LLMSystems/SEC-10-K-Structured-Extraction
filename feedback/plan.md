# 驗證方法規劃：第一性原理 + 外部參照

對應 feedback：[review.md](review.md)

核心轉向：從**統計門檻**（「跟歷史長得不一樣就警告」，必有偽陽/偽陰，到不了 100%）
轉向**第一性原理**（「違反就在邏輯或物理上不可能是對的」，偽陽性 ≈ 0）。

驗證分兩層：

- **Tier 1 — 自我一致性不變量**：只用 parser 自己的輸出就能檢查，違反即證明錯誤。能 100%，但能查的範圍有限（驗不了「定位本身對不對」）。
- **Tier 2 — 外部參照**：用與 parser 失敗模式無關的獨立來源（頁碼 / TOC / VLM）交叉驗證，才能驗證邊界與內容的正確性。

---

## Tier 1 — 自我一致性不變量（違反就一定錯）

| # | 規則 | 第一性原理 | 違反代表 | 偽陽性 |
|---|---|---|---|---|
| 1 | 區間合法 `0 ≤ start < end ≤ len(text)` | 索引不可能越界或反向 | 座標計算壞了 | 0 |
| 2 | 依編號排序後 range 單調且不重疊 `end[i] ≤ start[i+1]` | 同一段文字不能屬兩個 item；後面的 item 不能起在前一個結束前 | 邊界越界 / 排序去重錯 | 0 |
| 3 | **相鄰 extracted item 間不該有大段未指派文字** | 兩個相鄰 item 之間若隔著一大塊沒被任何 item 認領的內文，通常是中間漏抓了一個 item | 中間漏抓 item | 低（需排除合法夾在中間的 by_reference / not_applicable / 附錄） |
| 4 | **extracted item 內容字數總和不得低於絕對地板** | 一份合法 10-K 受 SEC 揭露義務約束，內容量有物理下限；低於此 = 抓錯主文件或 preprocess 把內容清光 | 抓錯文件 / 內容被清空 | 0（門檻設在「真實 10-K 不可能更短」的安全低標，非統計百分位） |

---

## Tier 2 — 外部參照（驗證邊界與內容）

邊界對錯**無法自證**（parser 靠標題定位，拿產物驗自己是循環），必須引入獨立參照。

| # | 規則 | 參照來源 | 做法 | 違反代表 |
|---|---|---|---|---|
| 7 | **VLM 首尾行比對**：VLM 偵測出的每個 item 第一行，須與 parser 抓到的第一行一致；最後一行亦同 | 多模態 LLM（獨立抽取，失敗模式與 regex 不相關） | 對渲染後的頁面，請 VLM 回報每個 item 的第一行 / 最後一行；與 parser `content_text` 的首行 / 末行比對 | 邊界截斷或越界（頭/尾沒對齊） |

> Tier 2 的價值在**三角驗證**：兩個獨立方法一致 → 信心趨近 100%；不一致 → 自動標記人工複查。
> 成本可控：不需餵整份文件，只需請 VLM 回報邊界行。

---

## 邏輯線（給報告用）

Tier 1 做到極限後，仍驗不了「parser 定位本身對不對」——因為要驗的正是它自己的產物。
剩下的只能靠 Tier 2 的獨立外部參照（頁碼 / TOC / VLM）。
所以 feedback 的兩點不是並列選項，而是「Tier 1 → 必然推導出 Tier 2」這條邏輯線。
